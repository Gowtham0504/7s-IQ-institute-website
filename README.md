# ⭐ 7s IQ Institute Website

A fully responsive and dynamic institute website developed as part of a **Web Development Internship**.  
The project showcases modern UI design, interactive components, and data-driven content using JSON.

---

## 🚀 Project Overview

The **7s IQ Institute Website** is designed to provide complete information about courses, training programs, and institute services.  
It includes dynamic course listings, detailed course pages, testimonials, gallery, and an admin panel UI.

This project follows **industry-standard frontend practices** and focuses on usability, responsiveness, and clean code structure.

---

## 🛠️ Technologies & Tools Used

- **HTML5** – Page structure  
- **CSS3** – Styling, animations, responsive layout  
- **JavaScript (ES6)** – Interactivity & dynamic content  
- **Bootstrap 5** – Responsive grid & components  
- **JSON** – Data management for courses & testimonials  
- **Git & GitHub** – Version control  

---

## ✨ Key Features

### 🌐 Website Features
- Responsive homepage with hero section
- Sticky navbar with active link highlight
- Dynamic course listing (loaded from JSON)
- Separate course details page with:
  - Curriculum
  - Advantages
  - Benefits
  - Fees & duration
- Testimonials section (JSON-based)
- Gallery page with images
- Contact form
- FAQ accordion section
- Counter animation for statistics
- Smooth scrolling and hover animations

### 🛠️ Admin Panel (UI Only)
- View courses, gallery, and testimonials
- Delete buttons (UI simulation)
- Modal popup instead of alert
- Responsive and interactive layout
